## 1.Linux系统
- 必会：`cd`、`ls`、`cp`、`mv`、`rm`、`vim/nano`、`tmux`（断了SSH程序不挂）
    
- 进阶：`nvidia-smi` 看显存、`htop` 看CPU、`df -h` 看磁盘、软链接 `ln -s`
    
- 避坑：不要在 `/home` 下乱装东西，学会用 `conda` 管理环境

### 2. Git 版本控制

实验室代码都是多人协作，不会 Git 会被骂。

- 必会：`git clone`、`add`、`commit`、`push`、`pull`、`branch`、`merge`
    
- 实战：学会提 Pull Request、解决冲突、看懂 `.gitignore`
    

> 建议：在 GitHub 上建一个自己的 d2l 练习仓库，每天 commit，养成习惯。
