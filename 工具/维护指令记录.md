# 维护指令记录

> 这里登记在对话里用到的开发和维护指令——换模型、加密钥、改配置这类。
> kael 负责往下记，一条一行，按时间排。

## 2026-09-20

| 指令 | 干什么 | 备注 |
| --- | --- | --- |
| `hermes auth add zai` | 把 GLM（z.ai）的密钥加进凭据池 | 在终端里交互输入，不回显、不进 history、不进聊天 |
| `hermes config set model.provider zai` | 把推理 provider 切成 GLM | — |
| `hermes config set model.default glm-5.2` | 默认模型换成 glm-5.2 | — |
| `hermes config set model.base_url ""` | 清掉原来指向 deepseek 的 base_url | 不然后面切到 GLM 还在往 deepseek 的地址发 |
| `hermes config set model.default glm-5.3-flash` | 换成 GLM 的 flash（快一些） | — |
| `hermes config set model.provider deepseek` | 切回 deepseek | — |
| `hermes config set model.default deepseek-flash` | 默认模型切回 deepseek-flash | — |

### 相关的只读命令

| 指令 | 看什么 |
| --- | --- |
| `hermes config get model` | 当前 provider / 模型 / base_url |
| `hermes auth list` | 凭据池里有哪几家、各自几条 |
| `hermes auth status zai` | 某家登录状态 |
| `hermes fallback list` | 主模型挂了会切到谁 |
| `hermes doctor` | 体检 |

## 备注

- `hermes fallback add` 是交互式的选择器；要脚本化就直接写 `fallback_providers`（`hermes config set`）。
- 改模型不会动记忆和笔记——那些是磁盘上的文件。
- 换 provider 之后，之前建的定时任务还锁在旧的 provider/model 上（它们有 snapshot），要一起搬得单独处理。
