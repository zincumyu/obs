# Recall（召回率）

直觉上说：模型“漏掉”了多少正样本。Recall 越高，漏报越少。
==🟠与 Precision（精确率）对比（核心区分）==

| 指标                 | 公式                 | 关注问题           | 怕什么          |
| ------------------ | ------------------ | -------------- | ------------ |
| **Precision 精确率**​ | $\frac{TP}{TP+FP}$ | 预测为正的里面，有多少是真的 | **误报**（把负当正） |
| **Recall 召回率**​    | $\frac{TP}{TP+FN}$ | 真实为正的里面，找出了多少  | **漏报**（把正当负） |
