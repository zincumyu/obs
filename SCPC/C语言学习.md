## 一、栈区 vs 堆区

它们是程序运行时内存的两个主要区域，区别很大：

### 栈区（Stack）

|特点|说明|
|---|---|
|存储内容|局部变量、函数参数、返回地址|
|分配方式|**自动分配、自动释放**（函数调用时压栈，返回时弹栈）|
|大小|较小（通常几MB），由操作系统限定|
|速度|**极快**（只需移动栈顶指针）|
|生命周期|随函数调用而生，随函数返回而灭|

```c
void func() {
    int x = 10;      // x 在栈上，func返回后自动消失
    int arr[100];    // arr 也在栈上
}   // 出栈，x和arr都没了
```

### 堆区（Heap）

|特点|说明|
|---|---|
|存储内容|动态分配的数据（malloc/new出来的）|
|分配方式|**手动申请、手动释放**（程序员控制）|
|大小|很大（几个GB，取决于物理内存）|
|速度|较慢（需要查找空闲内存块、处理碎片）|
|生命周期|从malloc到free，程序员说了算|

```c
void func() {
    int *p = (int *)malloc(100 * sizeof(int));  // 在堆上
    // p本身在栈上（它是一个局部变量），但它指向堆上的内存
    free(p);  // 必须手动释放
}
```
### 直观比喻

> **栈就像酒店的储物柜**：入住时分配，退房时自动清空，快速方便但空间有限。
> 
> **堆就像租仓库**：你需要多大租多大，想租多久租多久，但要自己负责归还，手续也麻烦一些。**

# 结构体访问
## 箭头运算符 `->` 的本质

`stu1->id` 等价于 `(*stu1).id`

也就是说：

1. `*stu1` 先解引用指针，得到整个结构体
    
2. `.id` 再访问这个结构体的 id 成员
    

所以这两行代码完全等价：

```c
stu1->id = 1001;       // 箭头写法（更常用）
(*stu1).id = 1001;     // 解引用+点号写法
```
---
```c
arr->id      // 等价于 arr[0].id，访问第1个
(arr+1)->id  // 等价于 arr[1].id，访问第2个
(arr+2)->id  // 等价于 arr[2].id，访问第3个
```
# 链表
### 2. 链表 vs 数组

**数组 = 一排连在一起的座位**

- 你知道第5个座位在哪（直接走过去就行）
    
- 但要在中间加个座位？所有人都得挪位置
    

**链表 = 火车车厢**

- 你不知道第5节车厢在哪（得从车头一节一节数过去）
    
- 但要在中间加一节车厢？解开铁钩，挂上新车厢，再连上就行
链表是什么？（数据结构本身）

链表就是**一串节点**，每个节点包含数据和指向下一个节点的指针。

```c
struct Node {
    int data;           // 数据
    struct Node *next;  // 指向下一个
};
```
增删查改要自己写!!!

**一级指针**就是一个普通的指针变量，它**存放的是另一个变量的地址**。
**二级指针**是一个指针，它**存放的是另一个指针变量的地址**。
int a = 10;
int* p = &a;    // p 是一级指针
int** pp = &p;  // pp 是二级指针，存放指针 p 的地址
pp 的类型是 int**，指向一个 int* 类型的指针。
通过 *pp 可以得到 p（即 a 的地址）。
通过 **pp 可以得到 a 的值。
3️⃣ 类比理解
一级指针：你有一个快递盒（变量），上面贴着地址（地址）。指针就是那张写着地址的小纸条。拿着纸条就能找到盒子。
二级指针：你把那张小纸条放在另一个信封里，信封外面又写了地址。二级指针就是这个信封的地址。你要先找到信封，取出里面的纸条，再用纸条找到盒子。

```
new_music->data = (char*)malloc(strlen(value) + 1);
执行过程分解
第1步：strlen(value)
        value 指向 "music1"
        计算出长度 = 6（不包括 \0）

第2步：malloc(6 + 1)

第3步：new_music->data = 0x2000
        把地址 0x2000 存入 data 指针变量
        现在 data 指向这块新内存

第4步：strcpy(new_music->data, value)
        把 "music1" 复制到 0x2000 处
内存中的样子
栈区：
    value → "music1"（字符串常量区）

堆区：
    new_music（地址 0x1000）：
    ┌──────────┬──────┬──────┐
    │ data:0x2000│ next│ prev│
    └──────────┴──────┴──────┘
         ↓
         0x2000: [m][u][s][i][c][1][\0]
```
