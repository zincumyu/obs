| **<br><br>定义<br><br>**                           | **<br><br>含义<br><br>** |
| ------------------------------------------------ | ---------------------- |
| `priority_queue<int>`                            | 大顶堆，从大到小出队             |
| `priority_queue<int, vector<int>, greater<int>>` | 小顶堆，从小到大出队             |
| `priority_queue<T, vector<T>, cmp>`              | 自定义比较，cmp 是结构体         |
